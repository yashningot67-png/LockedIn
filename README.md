# Locked In (Android)
Option A (Android Studio): File > Open > LockedIn folder > Run on phone.
Option B (no PC setup): GitHub par naya repo bana, ye saari files upload kar, Actions tab > "Build APK" run > artifact "LockedIn-apk" download kar, install kar.
Pehli baar app kholkar neeche ke 4 setup buttons on kar (alarm, full-screen, battery, accessibility).
